# L'esempio

Questa cartella c'è solo nel ramo `esempio`: i file iniziali compilati per l'help desk di Alpina Servizi (inventato, dalla
demo di MdExplorer): il dominio, i documenti di partenza, il codice C# del pilota, e il giro già fatto — glossario,
contesti con la mappa, allineamento con il codice. Chi crea un progetto «con l'esempio» li riceve in `ddd/` e
`codice/assistente-helpdesk/`, e la cartella del codice è già segnata per il grafo del codice.
